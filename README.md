# Sistem Informasi Rental Kendaraan (Mobil & Motor)

Aplikasi web berbasis Java (Servlet & JSP) dan MySQL untuk mengelola data pelanggan, armada kendaraan (mobil & motor), serta transaksi penyewaan kendaraan secara terintegrasi.

## Tautan Live Demo
* **Aplikasi Web Publik:** [Tempel Link Render Anda di Sini Nanti]

## Fitur Utama
* **Manajemen Data Pelanggan:** Menambah dan menampilkan data pelanggan (No. KTP, Nama Lengkap, No. HP, Alamat).
* **Manajemen Armada Kendaraan:** Menambah dan memantau status ketersediaan kendaraan (`Tersedia` / `Disewa`) beserta tarif sewa harian.
* **Transaksi Rental Otomatis:** Menghitung lama sewa (hari) dan total biaya sewa secara otomatis, sekaligus memperbarui status kendaraan menjadi `Disewa`.

## Teknologi / Tech Stack
* **Bahasa Pemrograman:** Java (JDK 17 / Servlet & JSP)
* **Web Server:** Apache Tomcat 9.0
* **Database:** MySQL 8 (Cloud Hosted via Aiven)
* **Frontend:** HTML5, CSS3, JSP
* **Deployment:** Docker & Render Cloud
